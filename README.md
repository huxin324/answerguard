# 答题守护（AnswerLock）——安卓防沉迷答题 App

孩子玩手机时，App 在后台计时；到点自动在**任何 App 上面**弹出答题窗口。
答对 → 继续玩；答错或超时 → 追加题目，连答还清后才能关掉。
今日时长用完 → 自动锁屏，需家长密码解锁。

## 功能一览

- 家长设置页：年级（**1~9 年级，覆盖小学+初中**）、出题科目（数学/语文/英语）、弹题间隔（30秒~10分钟）、答题倒计时、答错加题数（1~3）、每日最长可玩时长、家长密码（默认 1234）
- **教材进度自动匹配**：根据手机当前日期自动判断「上学期 / 下学期」（9月~1月=上学期，2月~8月=下学期），数学按人教版各年级各学期的知识点出题，例如：
  - 3上·多位数乘一位数 / 3下·两位数乘两位数
  - 5上·简易方程 / 5下·同分母分数加减
  - 7上·有理数与一元一次方程 / 7下·实数与平方根
  - 8上·幂的运算 / 8下·勾股定理与一次函数
  - 9上·一元二次方程 / 9下·反比例函数与锐角三角函数
- 语文、英语按学段（1~2 / 3~4 / 5~6 / 7~9）分档：古诗文默写、文学常识、英语词汇与语法
- 后台守护：**系统闹钟（AlarmManager）驱动**——到点弹题由系统排定，App 进程被华为冻结/杀掉也会被准时唤醒，离开 App 计时不中断；前台服务常驻 + 通知栏提示，家长点「启动守护」后即可把手机交给孩子
- 防绕过：上划划掉 App 自动拉起；进程被杀后闹钟自动恢复并补扣「死掉期间」的时间；重启手机开机自启恢复守护
- 全局弹窗：**悬浮窗方案**（WindowManager 直接绘制答题界面），只要「显示在其他应用上层」权限，孩子无论在玩什么都会被弹窗盖住；弹窗不属于任务列表，上划滑不掉、返回键关不掉
- 答题时暂停玩耍计时（作答时间不白扣），孩子把弹窗晾在后台也会被记为答错并重新弹到最前
- 锁屏 + 家长密码解锁；家长页可查看累计答题数、正确率
- **紧急解锁（v3.2）**：弹题窗右上角「🆘 紧急解锁」，家长急用手机时输一次家长密码就跳过——本轮题目作废，接下来 10 分钟不弹题也不扣今日时长，到点自动恢复守护（连错 3 次锁 60 秒，防孩子穷举密码）
- **跨天自动重置（v3.2）**：每天 0 点自动把「今日剩余时长 / 未答完的题 / 锁屏状态」清空；隔夜的中断不再算到今天的账上
- **语音讲解（v3.2 修好没声音 / v3.3 修「提示没有语音包」）**：补上了安卓 11+ 必需的 TTS 引擎可见性声明，并显式指定媒体音频通道。v3.3 起会**自动逐个探测手机里所有语音引擎**（华为 → 讯飞 → 百度 → 其他 → 谷歌），谁有中文语音数据就用谁并永久记住；如果每个引擎都没中文包，会自动打开系统的语音设置页，家长选一个引擎点「安装语音数据」即可。诊断区里的「🔊 测试语音讲解」可一键验证。
- 诊断区（默认收起）里的「⚡ 10 秒后弹题」：家长可随时验证弹窗是否正常

## 怎么把它变成手机上能装的 APK（二选一）

### 路线 A：GitHub 在线打包（推荐，电脑上什么都不用装）

1. 注册/登录 GitHub，新建一个仓库（Public 或 Private 均可）
2. 把本项目（AnswerLock 文件夹里的全部内容）上传到仓库，**注意 `.github` 文件夹要一起传**（它是隐藏文件夹，用网页上传或 GitHub Desktop 都可以）
3. 打开仓库的 **Actions** 页 → 左侧选 **Build APK** → 右上角 **Run workflow** → 运行
4. 等 2~3 分钟构建完成，进入该次运行页面，在 **Artifacts** 里下载 **AnswerLock-APK**
5. 解压得到 `app-debug.apk`，发到手机上安装

### 路线 B：本机 Android Studio 打包

1. 安装 Android Studio（Harbour 以上版本，自带 JDK17）
2. Open 打开 AnswerLock 文件夹，等 Gradle Sync 完成
3. 菜单 Build → Build App Bundle(s)/APK(s) → Build APK(s)
4. 生成的 APK 在 `app/build/outputs/apk/debug/` 下

## 安装后的首次设置（只有一个按钮）

首页从上到下就是一条流程：选年级 → 选弹题间隔 → 选科目等 → **一个大按钮** → 红色「使用须知」。

1. **安装 APK**（提示「未知来源应用」时允许）
2. **点蓝色「▶ 开始守护」** → 系统页面会自动逐个弹出（悬浮窗 → 通知 → 省电 → 闹钟 → 华为启动管理 → 华为后台弹窗），每项点「允许 / 打开」后返回，会自动继续下一项，最后自动开始守护
   - 按钮会跟着状态变色：**蓝＝可开始 → 绿＝守护中**（点一下开始、再点一下立刻停止，v3.2 取消了二次确认——守护中整页被家长密码锁着，孩子根本碰不到这个按钮）
   - 缺悬浮窗权限时按钮是灰的，点它会自动跳到权限页，开完回来自动继续
3. **第一次启动成功后，会自动弹出「锁住后台卡片」的图文引导（只需一次）**：照 4 步做——上滑停顿进最近任务 → 找到「答题守护」卡片 → 按住往下拉 → 点 🔒 锁图标 → 回 App 点「我锁好了」。点完 App 自动退到后台
   - 实测：**卡片上锁后，上划划不掉、一键清理也清不掉**（这是华为官方免清理通道）
   - 这个 🔒 是华为桌面的私有功能，App 没有 API 能替你打上，所以只能引导一次；点「我锁好了」之后 App 会永远记住，不再打扰
   - 卡片留在最近任务里，孩子点开也没用：设置页被家长密码锁住，只能看到「守护运行中 + 输密码」
   - 家长以后要改设置：从最近任务或桌面图标打开 App → 输家长密码 → 就是设置页
   - 忘了怎么锁？点首页那张红色「使用须知」卡，随时重看 4 步图文
4. **可选：防卸载保护**（使用须知卡里那一行）→ 点开后系统弹「要激活设备管理器吗」→ 点「激活」。作用是让「设置 → 应用 → 答题守护 → 强行停止」变灰、卸载前必须先取消激活；不开也能正常守护，只是孩子可以自己去设置里强行停止或卸载
5. 万一守护还是被结束了（比如先解锁卡片再清理），下次打开 App 会自动**扣掉中断的那段时间、追加惩罚题**，并弹提示告诉你被打断了几分钟
   - 单次最多扣 10 分钟；跨天的中断、以及超过 2 小时的中断（手机关机/一整天没碰）不扣时也不罚题
6. **锁屏即休息（v3.4）**：息屏/锁屏时「今日时长暂停计时、不弹新题」；如果弹题时正好锁屏（如来电话），已弹出的题会整个冻住——作答倒计时停住、不会超时加题，亮屏后从停住的地方原样接上。题不会因锁屏消失，锁屏也换不来「少答一题」。
7. **家长急用手机**：弹题窗右上角点「🆘 紧急解锁」→ 输家长密码 → 本轮题目作废，10 分钟内不弹题、不计时长，10 分钟后自动恢复

> v3.2 修复（用户真机反馈的 4 个问题）：
> ① 语音讲解没声音 —— 安卓 11 起有「软件包可见性」限制，manifest 里缺 `<queries>` 声明 TTS 引擎，TextToSpeech 会静默失败；已补上，并显式指定音频通道（媒体/语音），加了「🔊 测试语音讲解」自检按钮。
> ② 今天刚打开就提示「今日时长已用完」—— 两个原因都修了：`remaining` 没有跨天清零；隔夜中断被 `onGapKilled` 按全程扣时（昨天 22 点被杀、今天 8 点打开 = 扣 10 小时）。现在有日期戳自动重置，跨天/超 2 小时的断连不罚，单次扣时上限 10 分钟。
> ③ 弹题窗右上角新增「🆘 紧急解锁」。
> ④ 主按钮回到「点一下开始、点一下停止」，去掉红色二次确认。
>
> v3.0 改版：删掉了原来的「① 防清理保护」大卡片和「立即试弹一题」按钮，只留一个四色主按钮（蓝→绿→红→灰）；原来那段灰色说明改成红色的常驻「使用须知」，直接教怎么锁后台卡片。设备管理器降级成使用须知里的一行可选开关（它只能挡「设置里强行停止」和「卸载」，挡不住上划，价值不如从前，所以不再挡启动流程）。
>
> v2.8 修正：v2.7 曾误判「带锁也会被划掉」（录屏里那个锁其实是微信的）。用户重新实测确认：**只要给答题守护的卡片上锁，上划就杀不掉它**。所以 v2.8 恢复保留最近任务卡片，并把上锁流程压缩到「第一次启动后自动弹一次图文，点一下就永久记住」。锁本身无法由 App 自动设置（华为桌面私有功能 + 华为禁止侧载 App 用无障碍代点），这是唯一需要家长动手 10 秒钟的一步。媒体播放状态、常驻窗口继续保留。

## 华为 / 鸿蒙手机（Mate 60 等）必做的系统设置

华为对后台 App 的限制非常严格：App 在后台时整个进程会被「冻结」，冻结期间**连系统闹钟都会被压着不投递**（表现为：一离开 App 就不弹，一点开 App 积压的弹窗立刻出现）。必须给 App「免冻」资格：

1. **应用启动管理（最关键）**：点「开始守护」时会**自动带你跳一次** 设置 → 应用和服务 → 应用启动管理 → 「答题守护」→ 关闭「自动管理」→ 手动管理里把三项**全部打开**：
   - ✅ 允许自启动
   - ✅ 允许关联启动
   - ✅ 允许后台活动
   - 错过那一次也没关系：诊断区里的「📱 华为防冻结设置（图解）」随时可以重进
2. **省电豁免**：点「开始守护」时 App 会自动弹出系统对话框，点「允许」（等价于 设置→应用→答题守护→电池→不受限制）
3. **悬浮窗 + 后台弹窗**：华为把 SYSTEM_ALERT_WINDOW 拆成了两个开关，**两个都要开**。只开「悬浮窗」＝ 待在本 App 里能弹、一切到抖音就不弹。v2.5 起只有真的被系统拦过才会亮红条，点了直达应用信息页
4. **通知**：设置 → 通知和状态栏 → 「答题守护」→ 允许通知（含横幅、锁屏）
5. **卡片上锁（只需一次）**：第一次启动守护后会自动弹出图文引导，给最近任务卡片下拉上锁；上锁后上划、一键清理都带不走它
6. 完成后把间隔设 30 秒，切到抖音实测
7. **看 App 首页的自检行**：`权限 悬浮窗 ✅ 通知 ✅ 省电 ✅ 闹钟 ✅`——哪一项是 ❌ 就点 **「🔧 一键修复权限」**（缺一项修一项）

> 说明：弹题由系统闹钟驱动，App 首页每次打开都会自动检查并拉活守护服务、重排闹钟。但华为的「进程冻结」只有上面的系统设置能解开——特别是第 1、2 项，不做的话任何 App 都躲不掉（这是鸿蒙的硬限制，不是 Bug）。

## 已知局限（如实说明）

- **仅支持安卓**。iPhone 上第三方 App 无法拦截其他 App，苹果系统做不了这个功能
- 防清理分四层：① 设备管理器（挡「设置里的强行停止」和「卸载」）；② 最近任务卡片上锁（挡「上划」和「一键清理」，实测有效，只需一次）；③ 媒体播放状态 + 隐藏常驻窗口（让清理策略进一步跳过本进程）；④ 中断补罚（万一还是被杀，下次打开 App 扣时间 + 追加题）。若孩子主动去最近任务解锁卡片再清理，守护仍会被 force-stop 且不自愈——请配合应用锁使用
- 题库 v2.9：**每次弹题一次连答 5 题**（答错还会额外追加）。数学严格按人教版各年级「上/下学期」知识点出题——现在是什么学期就出什么学期的内容（9 月~1 月 = 上学期，2 月~8 月 = 下学期），每个年级每学期 5~7 种题型随机轮换，数值随机生成、题量无限；语文/英语为分档固定题库（每档 15~18 道，含古诗文、常识、词汇、语法）。如需完全对齐某版教材页码，可在此基础上替换/接入在线题库

## 语音讲解难听？换语音引擎（免费，1 分钟搞定）

App 使用手机系统的「文字转语音（TTS）」服务朗读讲解。如果你觉得声音机械难听，是手机默认语音引擎太老旧，换一个自然音色的引擎即可，**App 本身不用改**：

1. 打开手机「设置 → 更多设置 / 系统管理 → 文字转语音（TTS）/语音输入与输出」（不同品牌路径略有差异，可在设置里直接搜索「文字转语音」）
2. 查看「首选引擎」：
   - **华为/荣耀**：选「华为语音引擎」（设置里的引擎图标可下载「精致音色」，接近真人）
   - **小米**：选「小爱语音引擎」（自带小爱同学的音色，很自然）
   - **OPPO / vivo**：选厂商自带引擎并更新到最新版
   - 其他品牌或觉得都不理想：应用商店搜索安装 **「讯飞语记」** 或 **「Google 语音合成」**，装完回来这里选它
3. 点「安装语音数据 / 语音包」，下载**中文（普通话）**高清语音包（部分音色需在对应 App 里下载）
4. 点「试听」确认音色满意，然后重新打开答题弹窗即可生效

