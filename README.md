# 答题守护TV（AnswerLock TV）——电视版防沉迷答题 App

孩子看电视（直播、视频 App、点播）时，App 在后台计时；到点自动**全屏弹题盖在画面上**。
用遥控器上下左右选答案、OK 键确认。
答对 → 继续看；答错或超时 → 追加题目；今日时长用完 → 全屏锁定，家长密码解锁。

这是基于手机版 v3.5 的守护内核做的**电视专用版**（除华为鸿蒙电视外的安卓电视 / 电视盒子通用）。
电视系统的权限管控比手机松得多：悬浮窗授权一次就能全局弹题，也没有「一键清理后台」，
所以手机版那套防杀设置在电视版里全部不需要。

## 和手机版的区别

- **深色电视 UI**：横屏双栏家长页 + 全屏大字答题窗，字号按 2~3 米观看距离放大（题目 38sp、选项 26sp）
- **遥控器操作**：所有界面支持 D-pad 焦点移动（上下左右）+ OK 键确认；选项按「每行 2 个」排布、每次随机打乱位置（正确答案不会固定在某个选项）；弹窗弹出时焦点停在题目上，按一下方向键才进选项，避免系统替孩子先选中一个
- **26 键软键盘**：电视不一定有输入法，改密码 / 解锁设置 / 紧急解锁 / 时长用完解锁，全部用遥控器上下左右点键输入（字母 + 数字都能输，密码允许 4~8 位）
- **删掉了手机专属内容**：华为应用启动管理、后台弹窗、最近任务锁卡片、设备管理器开关 —— 电视上用不着
- 保留了手机版 v3.5 的全部核心逻辑：跨天自动重置、锁屏（电视关机/待机）暂停、中断补罚、紧急解锁 10 分钟、错题文字解答停留 10 秒

## 功能一览

- 家长设置页：年级（**1~9 年级，覆盖小学+初中**）、出题科目（数学/语文/英语）、弹题间隔（30秒~10分钟）、答题倒计时、答错加题数（1~3）、每日最长可看时长、家长密码（默认 1234）
- **教材进度自动匹配**：按当前日期自动判断上/下学期，数学按人教版知识点出题；语文、英语按学段分档
- 到点弹题：**一次连答 3 题**（答错按设置追加 1~3 题，追加的也要答完），全屏弹窗盖在视频画面上，返回键关不掉
- 家长急用电视：弹题窗右上角「🆘 紧急解锁」，输家长密码跳过，10 分钟不弹题不计时（连错 3 次锁 60 秒）
- 错题显示文字解答，停留 10 秒自动跳下一题
- 电视待机/关机不计时；重新开机后开机自启恢复守护
- 诊断区（默认收起）里的「⚡ 10 秒后弹题」：家长可随时验证弹窗是否正常

## 安装到电视

APK 打包方式见下文（和手机版共用同一套 GitHub Actions 配置）。装到电视上的步骤：

1. 把 APK 放进 U 盘，插到电视上
2. 用电视自带的「文件管理」（或当贝市场装的第三方文件管理器）打开 APK 安装
   - 提示「禁止安装未知来源应用」时：到 设置→安全 里允许「未知来源」后重试
3. 装好后电视桌面会出现「答题守护TV」（大横幅图标）
4. 打开 App → 选年级和间隔 → 点「开始守护」→ 按提示打开「显示在其他应用上层」（悬浮窗）权限 → 按返回键自动开始守护
5. 按 Home 键退出，切到孩子看的视频等着弹题即可

部分电视没有「未知来源」开关或没有文件管理器，可用 adb 安装（电脑执行 `adb install -r 答题守护TV.apk`，电视需先在 设置→关于 里连按「版本号」打开开发者模式并允许「USB/网络调试」）。

## 怎么打包 APK

### 路线 A：GitHub 在线打包（推荐，电脑上什么都不用装）

1. 新建一个 GitHub 公开仓库（例如 `answerguard-tv`），把本目录里的**全部文件**传上去
2. 仓库页 Actions → 允许 workflows → 选「Build AnswerLock APK」→ Run workflow
3. 跑完后在该次运行页面底部 Artifacts 里下载 APK

### 路线 B：本地打包

装 Android Studio 后直接 Open 本目录，Build → Build APKs。

## 给家长的话

- 家长密码默认 **1234**，主界面密码栏直接写着「初始密码 1234」；改过之后显示圆点，点「🔑 修改家长密码」改（原密码 → 新密码 → 确认）
- 电视上「显示在其他应用上层」权限一般在 设置→应用→答题守护TV→权限 里，第一次启动会自动带你去开
- 守护运行中孩子打开本 App 也改不了设置：整页被家长密码锁层挡住（26 键软键盘输密码解锁）
